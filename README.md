# Система платежей для электронной торговли

## Суть проекта:

Разрабатываем приложение системы платежей для электронного магазина. 

### Технический стек:

Для проекта требуется версия python не ниже `3.13`  
А так же версия Poetry не ниже `2.1.4`

В проекте используются:

* Менеджер пакетов `Poetry`.
* Линтеры: `mypy`, `black`, `isort`, `flake8`
* Фреймворк управления тестами `pytest`
* Инструмент сбора статистики покрытия кода `pytest-cov`


### Установка:

1. Склонируйте проект на свое локальное окружение командой:  
   git clone https://github.com/Uriy-T/python_study_skypro.git

2. Убедитесь, что в среде разработки для проекта используются интерпретатор python  
   и poetry версии в соответствии с указанными требованиями.

3. Для установки всех необходимых зависимостей выполните команду:
   ```bash
   poetry install

### Тесты и тестирование:

#### Аннотация 
Тесты расположены в пакете "tests" в корне проекта. Тесты параметризованы с помощью маркировки
`pytest.mark.parametrise()`. Тесты гораздо легче использовать благодаря тому, что в качестве значений параметров в
маркировку передаются не фиксированные значения, в результаты вычисления двух функций-форматеров `param_packer_old` и
`value_packer_old` в которые передается набор тестовых данных, приводимый ими к нужному для маркировки состоянию. Что
позволяет менять не сами тесты, а только сами наборы данных.
Наборы данных вынесены в отдельный пакет и разбиты тематически соответственно названию тестируемого модуля и функции.
Функции-форматеры можно найти по пути: src/tools/dataset_handlers.py

Тесты разделены на тестовые наборы. Класс == тестовый набор.
Для удобства управления прогонами тестов во время отладки тестам указаны тематические маркировки. Весь доступный их список можно найти в файле pytest.ini

#### Запуск тестов
Все тесты разом можно запустить командой:

```bash
  pytest
  ```
Если требуется запустить конкретные тесты отдельно, то используйте команды:

* Запуск конкретного теста:
```bash
  pytest -k 'Имя теста/маркировки/класса или его часть'
  ```
Часть имени теста/маркировки/класса должна достаточно четко указывать на этот самый тест/тестовый набор. Чтобы в прогон не попали другие, обладающие сходным наименованием с общей частью в названии.

* Запуск тестов со сбором покрытия:

```bash
  pytest --cov=src --cov-report=html
  ```
Перед запуском команды для полной уверенности в актуальности данных отслеживания покрытия рекомендуется удалить из проекта пакет htmlcov и файл .coverage.

### Модульный состав:

Все основные функциональные модули расположены в пакете src:
* product.py - содержит реализацию класса объекта Product. Методы инициализации объекта и методы манипуляции им. Модуль содержит дочерние классы Smartphone и Lawngrass описывающие продукты конкретного вида.
* category.py - содержит реализацию класса объекта Category. Методы инициализации объекта и методы манипуляции им.
